

# Teach Me

Teach Me — оқу материалдарын есте сақтауға ыңғайлы сұрақ-жауап карточкаларына айналдыратын Django веб-қосымшасы. Жоба оқу мәтіні негізінде карточкалар құруға және оларды жеке бетте қарауға арналған.

Қосымшада екі жұмыс режимі қарастырылған:

- **DEMO** — алдын ала дайындалған оқу мәтіні мен үш карточканы пайдаланады.
- **LIVE** — Gemini API арқылы берілген мәтіннен жаңа карточкалар генерациялайды.

## Технологиялар

- Python
- Django
- python-dotenv
- Gemini API (LIVE режимі үшін)

## Мүмкіндіктер

- Оқу материалының атауы мен мәтінін енгізу.
- DEMO режимінде тұрақты үш карточка алу.
- LIVE режимінде Gemini арқылы 3–8 карточка генерациялау.
- Әр карточкада сұрақ, жауап және бастапқы мәтіннен алынған дәйексөз болуы.
- Карточкаларды жеке URL арқылы ашу.
- Жаңартудан кейін карточка деректерін дерекқордан қайта алу.

## Орнату және іске қосу

### 1. Репозиторийді жүктеу

```bash
git clone <repository-url>
cd teachme
```

`<repository-url>` орнына өз репозиторийіңіздің сілтемесін қойыңыз.

### 2. Виртуалды орта құру

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Тәуелділіктерді орнату

```bash
python -m pip install -r requirements.txt
```

`requirements.txt` құрамында:

```text
Django
python-dotenv
```

### 4. Орта айнымалыларын баптау

Жобаның түбіріндегі `.env.example` файлын `.env` деп көшіріңіз.

**Windows (PowerShell):**

```powershell
Copy-Item .env.example .env
```

**macOS:**

```bash
cp .env.example .env
```

`.env` — жергілікті құпия конфигурация файлы. Оны Git репозиторийіне жарияламаңыз және API кілтін басқа адамдарға жібермеңіз.

### 5. Дерекқор миграциялары

```bash
python manage.py migrate
```

### 6. Серверді іске қосу

```bash
python manage.py runserver 127.0.0.1:8000
```

Браузерден ашылатын мекенжай:

http://127.0.0.1:8000/

## Жұмыс режимдері

### DEMO режимі

DEMO — жобаны Gemini API кілтінсіз тексеруге арналған режим.

- Дайын `DEMO_TEXT` мәтіні пайдаланылады.
- `DEMO_CARDS` ішіндегі үш дайын карточка қайтарылады.
- Карточкалар саны мен мазмұны тұрақты.
- Басқа мәтін енгізілсе, DEMO режимі оны қабылдамайды.

Бұл режим жобаның негізгі интерфейсін API шығындарынсыз тексеруге мүмкіндік береді.

### LIVE режимі (қосымша)

LIVE режимі Gemini API-ға сұраныс жібереді. Оны қолдану үшін `.env` файлында төмендегі айнымалыларды баптау қажет:

```env
TEACHME_MODE=live
GEMINI_API_KEY=your_api_key
GEMINI_MODEL=your_model_name
GEMINI_TIMEOUT_SECONDS=25
```

Айнымалылардың мағынасы:

| Айнымалы | Мақсаты |
|---|---|
| `TEACHME_MODE` | `demo` немесе `live` режимін таңдау |
| `GEMINI_API_KEY` | Gemini API кілті |
| `GEMINI_MODEL` | Қолданылатын Gemini моделі |
| `GEMINI_TIMEOUT_SECONDS` | Сұраныстың күту уақыты, 1–60 секунд |

LIVE режимі міндетті емес. API кілті мен модель дұрыс бапталмаса, LIVE генерациясы орындалмайды.

LIVE режимінің нақты API арқылы сәтті жұмыс істегені бұл README жазылған кезде расталған жоқ.

## Карточкаларды тексеру

Генерацияланған карточкаларда мына өрістер болуы керек:

- `question` — сұрақ;
- `answer` — жауап;
- `source_quote` — бастапқы мәтіннен алынған дәйексөз.

Карточкаларды тексеру кезінде:

- карточкалар саны 3 пен 8 аралығында болуы керек;
- қажетті үш өрістің барлығы мәтін түрінде және бос емес болуы керек;
- сұрақтар қайталанбауы керек;
- өрістердің ұзындығы белгіленген шектен аспауы керек;
- `source_quote` бастапқы мәтіннің ішінде дәл кездесуі керек.

**Дәйексөз тексеруінің шегі:** код дәйексөздің бастапқы мәтінде бар екенін тексереді. Бірақ оның жауаптың мағынасын толық дәлелдейтінін, контекстке сай екенін немесе жауаптың шындыққа сәйкес екенін автоматты түрде дәлелдемейді.

## URL мекенжайлары

`study/urls.py` файлында екі маршрут көрсетілген:

| URL | View | Мақсаты |
|---|---|---|
| `/` | `home` | Негізгі бет және карточка генерациясы |
| `/sources/<int:pk>/` | `source_detail` | Белгілі бір материалдың жеке беті |

Мысалы, `/sources/1/` мекенжайы дерекқордағы ID мәні 1 болатын материалдың жеке бетін ашады.

## Қауіпсіздік және шектеулер

- Қазіргі нұсқада пайдаланушыны тіркеу және авторизация жүйесі жоқ.
- Материал иесін анықтау және иелік құқығын тексеру механизмі жоқ.
- Жеке материалға қолжетімділік пайдаланушы аккаунтымен шектелмейді.
- `.env` файлы құпия ақпаратты сақтау үшін қолданылады және Git-ке жіберілмеуі керек.
- Дәйексөздің мәтінде кездесуі оның мағыналық дұрыстығына кепілдік бермейді.

Бұл нұсқаны толыққанды көппайдаланушылық қауіпсіз жүйе деп қарастыруға болмайды.

## Жобаны тексеру

Төмендегі командаларды студент жобаның түбірлік қалтасында, виртуалды орта белсенді кезде өзі орындайды.

### Django конфигурациясын тексеру

```bash
python manage.py check
```

### Study қосымшасының тесттері

```bash
python manage.py test study
```

Бұл команда `study` қосымшасындағы тесттерді іске қосады. Тесттердің нақты саны мен нәтижесі терминал қорытындысы арқылы анықталады.

### Модель миграцияларын тексеру

```bash
python manage.py makemigrations --check --dry-run
```

Бұл команда модельдер мен миграциялардың арасында жаңа өзгерістер бар-жоғын тексереді. `--dry-run` миграция файлын сақтамай тексеруге мүмкіндік береді.

Бұл командалар README ішіндегі нұсқаулық ретінде берілген. Олардың осы құжатты дайындау кезінде орындалғаны немесе сәтті аяқталғаны туралы мәлімдеме жасалмайды.

## Орындау нәтижелері

| Тексеру | Нәтиже |
|---|---|
| `check` | Нақты қорытынды көрсетілмеген |

Teach Me жобасы оқу мәтіндерін сұрақ-жауап карточкаларына айналдыруға арналған. DEMO режимі тұрақты үш карточкамен жұмыс істейді, ал LIVE режимі Gemini API арқылы қосымша генерация мүмкіндігін ұсынады.
